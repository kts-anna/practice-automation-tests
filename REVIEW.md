# Ревью проекта

Замечания оставлены прямо в коде комментариями вида `# 🟡 | AI`. Найти все:

```bash
grep -rn "| AI" --include='*.py' --include='*.txt' --include='*.yml' .
```

🔴 — ломает поведение, 🟡 — стоит поправить, 🟢 — на усмотрение автора.

## Что хорошо

- Аккуратный Page Object: базовый класс, переиспользуемые компоненты `Popup`
  и `JetpackForm`, локаторы не завязаны на меняющиеся id.
- Нет `time.sleep` — всё на явных ожиданиях.
- Отчёт Allure продуман: эпики, фичи, шаги на русском, при падении
  прикладываются скриншот, URL и HTML, заполнена вкладка Environment.
- Тест-кейсы задокументированы в README и совпадают с кодом по ID.
- Есть CI на GitHub Actions, браузер и headless переключаются опциями.

## Главное (🟡)

| Где | Суть |
|-----|------|
| `pages/base_page.py` — `click()` | Запасной клик через JavaScript прячет перекрытые элементы: тест зелёный там, где пользователь кликнуть не сможет. |
| `pages/components/jetpack_form.py` — `_wait_submitted()` | Вложенное ожидание: `page.find()` с таймаутом 10 с внутри `until`, из-за этого реальные таймауты не соответствуют заявленным. |
| `tests/test_form_fields.py` — F-01 | Ожидаемое значение строится тем же кодом, что проверяемое, — проверка тавтологична. |
| `tests/test_calendar.py` — C-N4 | Отказ отправки «доказан» только отсутствием успеха за 3 с — при медленном сервере тест ложно зелёный. |
| `tests/test_ads.py` — A-N1 | Проверка с `timeout=0` идёт до инициализации скриптов попапа и пройдёт при любой задержке рекламы. |
| `requirements.txt` | Версии через `>=` — CI может упасть от нового релиза зависимости. |

## Мелочи (🟢)

- `pages/base_page.py` — неиспользуемый `press_escape`.
- `pages/components/popup.py` — текст-маркер подставляется в XPath без экранирования кавычек.
- `pages/modals_page.py` — локаторы-атрибуты экземпляра названы капсом; `open_form_modal`
  отбрасывает результат `is_open`, а `open_simple_modal` не ждёт вовсе.
- `pages/ads_page.py` — название шага «…под рекламой» неверно для A-07.
- `tests/test_calendar.py` — `date.today()` на этапе импорта и захардкоженная «будущая» дата.
- `conftest.py` — нет вложений при падении в setup; импорты внутри функции.
- `.github/workflows/ui-tests.yml` — Firefox не проверяется в CI, нет кэша pip, отчёт не собирается.
- `README.md` — в «Структуре проекта» нет `pages/components/jetpack_form.py` и `.github/`.
