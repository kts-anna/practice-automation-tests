# UI-автотесты для practice-automation.com

Проект автоматизированного UI-тестирования страниц
[Календарь](https://practice-automation.com/calendars/),
[Модальные окна](https://practice-automation.com/modals/),
[Рекламные окна](https://practice-automation.com/ads/)
и поля Message на странице [Form Fields](https://practice-automation.com/form-fields/).

## Стек

- Python 3.12+
- Selenium 4 (драйверы браузеров скачиваются автоматически через Selenium Manager)
- Pytest
- Allure Report
- Паттерн Page Object Model
- Браузеры: Chrome, Firefox

## Структура проекта

```
├── config.py                 # базовый URL и таймауты
├── conftest.py               # фикстуры браузера и страниц, скриншоты в Allure при падении
├── pytest.ini                # настройки pytest
├── requirements.txt
├── pages/                    # Page Object'ы
│   ├── base_page.py          # общие действия и ожидания
│   ├── calendar_page.py
│   ├── modals_page.py
│   ├── ads_page.py
│   ├── form_fields_page.py
│   └── components/popup.py   # переиспользуемый компонент модального окна
└── tests/
    ├── test_calendar.py
    ├── test_modals.py
    ├── test_ads.py
    └── test_form_fields.py
```

## Запуск

```bash
git clone <ссылка на репозиторий>
cd <папка проекта>
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

pytest                                   # Chrome (по умолчанию)
pytest --browser=firefox                 # Firefox
pytest --headless                        # без окна браузера
pytest -m negative                       # только негативные
pytest tests/test_modals.py              # одна страница
```

> На сайте модальные окна и реклама не показываются при включённом блокировщике рекламы.
> Тесты запускают чистый профиль браузера без расширений.

## Allure-отчёт

Результаты пишутся в папку `allure-results` автоматически. Для просмотра нужен
[Allure CLI](https://allurereport.org/docs/install/) (требуется Java 8+):

```bash
allure serve allure-results
```

В отчёте: эпик → фича (страница) → тесты с понятными названиями и шагами.
При падении теста прикладываются скриншот, URL и HTML страницы.
Во вкладке Environment указаны браузер, версии Python и Selenium.

## Тестовые сценарии

Предусловие для всех тестов: открыт браузер, открыта тестируемая страница.

### Календарь — https://practice-automation.com/calendars/

> Особенность страницы: поле даты реализовано формой Jetpack — это текстовое поле
> с подсказкой формата `YYYY-MM-DD` и встроенной валидацией. Всплывающий календарь
> (jQuery UI Datepicker) на странице не подключён, поэтому тесты проверяют ввод даты
> и валидацию формы. Признак успешной отправки — класс `submission-success` у формы
> и параметр `contact-form-sent` в URL; признак ошибки — `aria-invalid="true"` у поля
> и текст ошибки под ним.

| ID | Тип | Сценарий | Шаги | Ожидаемый результат |
|----|-----|----------|------|---------------------|
| C-01 | + | Открытие страницы | Открыть страницу | Заголовок «Calendars», поле даты отображается |
| C-02 | + | Подпись и подсказка | Открыть страницу | Видны подпись «Select or enter a date» и подсказка «YYYY-MM-DD» |
| C-03 | + | Формат поля | Проверить атрибут data-format поля | Значение `yy-mm-dd` |
| C-04 | + | Ввод корректной даты | Ввести 2025-12-31, убрать фокус | Значение сохранено, ошибки нет |
| C-05 | + | Отправка корректных дат | Ввести дату (2025-12-31 / сегодня / 2024-02-29 / 2030-01-01), Submit | Форма отправлена |
| C-06 | + | URL после отправки | Ввести 2025-12-31, Submit | В URL есть `contact-form-sent` |
| C-07 | + | Поле после отправки | Ввести 2025-12-31, Submit | Поле даты скрыто |
| C-08 | + | Исправление ошибки | Ввести «abcdef», Submit, затем ввести 2025-12-31, Submit | Ошибка снимается, форма отправлена |
| C-09 | + | Очистка поля | Ввести дату и стереть её | Поле пустое |
| C-N1 | − | Буквы вместо даты | Ввести «abcdef», Submit | Форма не отправлена, ошибка «Please enter a valid date.» |
| C-N2 | − | Неверный формат | Ввести «31.12.2025», Submit | Форма не отправлена, ошибка «Please enter a valid date.» |
| C-N3 | − | Несуществующая дата | Ввести «2025-13-45», Submit | Форма не отправлена, ошибка «Please enter a valid date.» |
| C-N4 | − | Пустое поле | Не вводить дату, Submit | Форма не отправлена |
